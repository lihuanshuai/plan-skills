# plan-skills

项目实施计划的编写与执行技能。技能目录直接位于仓库根目录，供其他技能仓通过 Git subtree 纳入自己的 `skills/plan/` 目录。

| 技能 | 用途 |
| --- | --- |
| [write-project-plan/](write-project-plan/) | 基于仓库证据编写可执行的实施计划 |
| [execute-project-plan/](execute-project-plan/) | 按已确认的计划实施、验证并回写进度 |

`execute-project-plan` 在缺少计划时使用 `write-project-plan`。两个技能从 [backend-skills](https://github.com/lihuanshuai/backend-skills) 的 `5870a199cfdf9007e90233fdcad93c8d0dc1a33f` 迁入。
